# 💀 Maybach Bot — личный финансовый надзиратель в Telegram

Бот, который считает твои деньги, откладывает их на цели и **не даёт сливать их на ерунду**.
Данные хранятся у тебя (на компьютере или на твоём сервере), а слушается бот только тебя.

- 📱 **Мини-приложение прямо в Telegram** — баланс, цели с фото, календарь и история на одном экране,
  запись траты в два касания. Кнопка «Приложение» слева от поля ввода.
- 💰 **Доходы и расходы** — пишешь в чат `350 шаурма` или `+2000 зп`, бот сам разберётся.
- ⚖️ **Правило 80/20** — с каждого дохода 80% сразу уходит в цели, 20% — на жизнь. Процент меняется.
- 🎯 **Цели с фото** — несколько целей, у каждой фото (можно альбомом), прогресс, срок, прогноз «когда накоплю».
- 📅 **Календарь** — сколько заработал и потратил за месяц, отметки по дням, подробности любого дня.
- 📊 **Статистика** — траты по категориям, сколько ушло «на хотелки», сравнение с прошлым месяцем, жёсткий вердикт.
- 🛑 **«Хочу купить»** — перед покупкой бот покажет, сколько дней работы она стоит и насколько отодвинет цель.
  Можно взять паузу на 24 часа — бот сам напомнит.
- 🔥 **Жёсткая мотивация в стиле Дэвида Гоггинса** — после каждой траты, утром и вечером.
  Два режима: «🔥 Жёстко» и «☠️ Без цензуры» (с матом, включается в настройках).
- 🧠 **Учится на твоих исправлениях** — один раз выбрал категорию для «бенз» — дальше бот знает сам.
- 🤖 **Нейросеть для категорий (по желанию)** — бесплатная, подключается одной командой.
- ↩️ **Отмена любой записи** в один клик — балансы и цели пересчитываются точно до копейки.
- 📤 **Выгрузка в Excel (CSV)** и 💾 **бэкап базы** прямо в Telegram.

## ☁️ Бот 24/7 на сервере — рекомендуемый способ

На сервере бот работает круглосуточно, даже когда ноутбук выключен, и сам поднимается после перезагрузки.

### 1. Арендуй сервер (VPS)

- **Локация — за границей** (Нидерланды, Финляндия, Германия). С 2026 года Telegram в России замедлен,
  и `api.telegram.org` с российских серверов часто недоступен — бот просто не достучится до Telegram.
  Заграничная локация заодно открывает доступ к бесплатным нейросетям.
- **Система — Ubuntu 24.04** (подойдёт и 22.04 или Debian 12).
- **Минимальная конфигурация** (1 ядро, 1 ГБ памяти, 10 ГБ диска) — боту хватит с запасом.
- Стоит от ~150–300 ₽ в месяц. Многие хостеры принимают российские карты и СБП и дают
  локацию в Нидерландах (например, FirstVDS, RuVDS, 4VPS — цены на сентябрь 2026, проверь актуальные).

После покупки хостер пришлёт **IP-адрес** и **пароль root**.

### 2. Подключись к серверу

В Windows открой «Терминал» (или PowerShell), в macOS — «Терминал», и введи:

```bash
ssh root@IP_СЕРВЕРА
```

(на вопрос `Are you sure you want to continue connecting` ответь `yes`, затем вставь пароль — при вводе он не отображается).

### 3. Установи бота одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/daaamngg/mmmmmmmaybach/HEAD/deploy/install.sh | bash
```

Скрипт сам поставит всё нужное и спросит:
1. **Токен бота** (ввод скрыт — просто вставь и нажми Enter);
2. **Твой Telegram ID** (узнать — [@userinfobot](https://t.me/userinfobot); можно заранее: `… | OWNER_ID=123456789 bash`);
3. **Часовой пояс** — Enter, если Москва, или например `Asia/Yekaterinburg`.

Заодно он настроит **мини-приложение**: поставит Caddy (веб-сервер, который сам получает бесплатный
HTTPS-сертификат) и выдаст приложению адрес вида `https://1-2-3-4.sslip.io` — свой домен не нужен.

В конце увидишь «Готово! Бот работает 24/7» и «📱 Мини-приложение доступно». Открой бота в Telegram
и отправь `/start` — слева от поля ввода появится кнопка **«Приложение»**.

> ⚠️ Одновременно бот может работать только в одном месте. Запустил на сервере — останови копию на ноутбуке.

**Бот не отвечает?** Выполни на сервере `finbot doctor` — он проверит токен, связь с Telegram, владельца,
мини-приложение и скажет, что исправить. Если ты пишешь боту, а он молчит, он один раз пришлёт
«🔒 Это личный бот… Твой Telegram ID: …» — значит, в настройках указан другой ID: `finbot owner ТВОЙ_ID`.

**Уже ставил бота раньше?** Просто выполни `finbot update` — обновление само добавит мини-приложение.

### Управление ботом на сервере

| Команда | Что делает |
|---|---|
| `finbot doctor` | **бот молчит? — проверит всё и скажет, что исправить** |
| `finbot status` | работает ли бот |
| `finbot logs` | лог в реальном времени (выход — Ctrl+C) |
| `finbot restart` | перезапустить |
| `finbot update` | скачать новую версию и перезапустить (данные и настройки сохраняются) |
| `finbot token` | сменить токен — например, после перевыпуска в @BotFather (`/revoke`) |
| `finbot owner ID` | сделать владельцем бота этот Telegram ID |
| `finbot webapp` | открывается ли мини-приложение |
| `finbot webapp on [домен]` / `off` | включить (HTTPS настроится сам) или выключить мини-приложение |
| `finbot ai` | подключить или отключить нейросеть для категорий |
| `finbot ai-status` | отвечает ли нейросеть (бот проверяет её при каждом запуске) |
| `finbot backup` | сохранить копию базы и фото в `/root` |
| `finbot import ПУТЬ` | перенести данные с ноутбука |

Данные лежат в `/var/lib/finbot/data`, настройки и токен — в `/etc/finbot.env` (доступ только у root).

### Перенос данных с ноутбука на сервер

Если ты уже вёл учёт на ноутбуке: останови бота на ноутбуке, затем в терминале **на ноутбуке**, в папке с ботом:

```bash
scp -r data root@IP_СЕРВЕРА:/root/
```

и **на сервере**:

```bash
finbot import /root/data
```

Бот сохранит на всякий случай прежние данные сервера и продолжит с твоими записями, целями и фото.

<details>
<summary>Вариант с Docker</summary>

Если на сервере уже есть Docker: скопируй репозиторий, создай `.env` (как в `.env.example`) и выполни

```bash
docker compose up -d --build
docker compose logs -f
```

Данные хранятся в томе `finbot-data`. Мини-приложению нужен HTTPS: поставь перед контейнером свой
веб-сервер (Caddy, nginx) с сертификатом, направь его на порт 8080 контейнера (см. `docker-compose.yml`)
и впиши адрес в `WEBAPP_URL`.
</details>

## 💻 Запуск на своём компьютере

Подходит, чтобы попробовать. Бот работает, пока включён компьютер (сообщения, отправленные за время
простоя, он обработает при следующем запуске, если прошло не больше суток).
Из России понадобится включённый VPN — иначе бот не достучится до Telegram.

1. Создай бота: [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй **токен** вида `1234567890:AAH...`.
2. Установи **Python 3.10+**: <https://www.python.org/downloads/> (на Windows отметь «Add python.exe to PATH»).
3. Скачай бота: **Code → Download ZIP** на GitHub (и распакуй) или `git clone`.
4. **Windows:** дважды кликни `start.bat` — откроется Блокнот, вставь токен после `BOT_TOKEN=`, сохрани и закрой.
   **macOS / Linux:** `./start.sh` (первый раз создаст `.env` — впиши токен и запусти ещё раз).
5. Открой бота в Telegram и нажми **/start** — теперь он твой, остальных игнорирует.

<details>
<summary>Запуск вручную</summary>

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt        # Windows: .venv\Scripts\pip ...
cp .env.example .env                              # и впиши BOT_TOKEN
.venv/bin/python run.py                           # Windows: .venv\Scripts\python run.py
```
</details>

## 📱 Мини-приложение

Открывается кнопкой **«Приложение»** слева от поля ввода (или командой `/app`) прямо внутри Telegram:

- **Главная** — сколько можно тратить (и сколько в день до конца месяца), сколько в целях и в копилке,
  итоги месяца, серия без «хотелок», главная цель с фото и жёсткая цитата.
- **➕ Запись** — сумма, комментарий, категория угадывается на лету (ещё до сохранения видно,
  сколько уйдёт в цели или сколько останется на расходы), можно задним числом.
- **🎯 Цели** — фото (добавляются прямо с телефона), прогресс, прогноз «когда накоплю», пополнение.
- **📅 Календарь** — траты и доходы по дням (чем больше потратил, тем краснее день), категории, вердикт.
- **🧾 История** — все записи: поменять категорию (бот запомнит) или удалить.

Всё, что делаешь в приложении, сразу видно в чате, и наоборот — это один и тот же бот и одна база.

**Как это устроено и почему безопасно.** Приложение отдаёт сам бот, а Caddy на сервере даёт ему HTTPS
(Telegram открывает мини-приложения только по HTTPS). Адрес — бесплатный `<ip-сервера>.sslip.io`
и запасной `<ip-сервера>.nip.io`: сертификаты для них выдаёт Let's Encrypt, и если у одного домена
временно кончился общий лимит, бот сам возьмёт другой. Каждый запрос приложения подписан Telegram —
бот проверяет подпись своим токеном и пускает только владельца. Даже зная адрес, чужой человек
увидит лишь «Вход закрыт».

Свой домен: `finbot webapp on fin.example.com` (A-запись домена должна указывать на IP сервера;
бот запомнит его, обновления адрес не меняют; вернуть бесплатный адрес — `finbot webapp on auto`).
Хочешь запасной центр сертификации ZeroSSL — укажи почту: `WEBAPP_EMAIL=you@example.com finbot webapp on`.
Кнопка не появилась — `finbot doctor`: чаще всего в панели хостинга закрыты входящие порты 80 и 443.

На домашнем компьютере мини-приложение не включается (нет HTTPS-адреса) — бот работает в чате как обычно.

## ✍️ Как пользоваться

### Быстрый ввод — просто пиши в чат

| Пишешь | Что будет |
|---|---|
| `350 шаурма` | расход 350, категория «Кафе и доставка» |
| `такси 500` | расход 500, «Транспорт» |
| `+2000` или `+2000 зарплата` | доход 2000: 1600 в цели, 400 на расходы |
| `зп 50к`, `аванс 30000` | тоже доход — бот понимает «зп», «аванс», «премия», «продал»… |
| `вчера 700 такси` | расход задним числом |
| `12.09 1500 продукты` | расход на конкретную дату |
| `2к`, `1.5к`, `2кк`, `3 ляма` | 2 000, 1 500, 2 000 000, 3 000 000 |

Ошибся — **↩️ Отменить**. Перепутал доход с расходом — **🔄 Это доход**.

### Категории: словарь, память и нейросеть

1. **Словарь.** Бот знает сотни слов: шаурма, пятёрочка, такси, wb, пиво, зал, аптека…
2. **Память.** Не узнал слово — под записью сразу появятся кнопки категорий. Выбрал один раз —
   бот запомнил и в следующий раз определит сам (и по фразе целиком, и по главному слову:
   научил на «бенз 95» — поймёт и «бенз 92»). Твой выбор всегда главнее словаря.
3. **Нейросеть (по желанию).** Подключается для слов, которых бот ещё не знает. Думает в фоне:
   запись появляется мгновенно, а через секунду категория уточняется (с пометкой 🤖).
   Нейросеть получает только текст комментария — без сумм и дат. Её догадки не перебивают твои исправления.

**Как подключить нейросеть бесплатно:**
1. Возьми ключ (карта не нужна):
   - **Groq** — <https://console.groq.com/keys> (ключ `gsk_…`, до 1000 запросов в день бесплатно);
   - или **OpenRouter** — <https://openrouter.ai/keys> (ключ `sk-or-…`, до 50 запросов в день бесплатно).
   Регистрация может не пустить с российского IP — тогда зарегистрируйся через VPN.
2. На сервере выполни `finbot ai` и вставь ключ — бот сразу сделает пробный запрос и скажет, работает ли ключ.
   Можно и сразу при установке: `curl … | OWNER_ID=… AI_API_KEY=gsk_… bash`.
   На компьютере — впиши ключ в `.env` в строку `AI_API_KEY=` и перезапусти бота.
3. Состояние нейросети видно в боте: **⚙️ Настройки → 🤖 Нейросеть для категорий** («работает ✅» или что не так).

В нейросеть уходят только незнакомые слова, поэтому бесплатных лимитов хватает с большим запасом.
Без нейросети бот работает так же — просто незнакомое слово один раз попросит выбрать вручную.

### Правило 80/20

Каждый доход делится автоматически: **80% в цели**, **20% на расходы** (процент — в ⚙️ Настройках,
а для конкретного дохода — кнопкой «⚖️ Изменить %» под ним).
Отчисления делятся между целями по **долям** (кнопки ➖/➕ в карточке цели; доля 0 — цель на паузе).
Заполненная цель больше не получает денег — излишек перетекает в остальные. Если целей нет —
деньги копятся в «🆓 Свободных накоплениях», их потом можно раскидать по целям.

### Цели

- Создание: **🎯 Цели → ➕ Новая цель** → название → сумма → фото.
- Фото можно прислать **прямо в чат** в любой момент — бот спросит, к какой цели его прикрепить.
- В карточке цели: пополнить (с расходов, из свободных накоплений или «уже было отложено до бота»),
  снять (с жёстким вопросом «ты уверен?»), доля, срок, листание фото.
- Цель достигнута → бот празднует → **🛒 Купил!** списывает её как покупку и отправляет в 🏆 архив.

### 🛑 Хочу купить

Напиши, что хочешь купить: `кроссовки 12000`. Бот покажет:
какую часть денег на расходы это съест, сколько дней работы это стоит, насколько ближе стала бы цель.
Дальше выбор: **💪 Не покупаю** (и можно сразу отправить эти деньги в цели), **⏳ Подумаю 24 часа**
(бот напомнит через сутки) или **🤡 Всё равно куплю**.

### Команды

`/app` приложение · `/balance` баланс · `/goals` цели · `/calendar` календарь · `/stats` статистика · `/want` хочу купить ·
`/history` последние записи · `/motivation` мотивация · `/settings` настройки · `/export` CSV · `/help` справка · `/cancel` отмена

## 🔒 Приватность и данные

- Бот работает на **твоём** компьютере или сервере (long polling): никаких чужих серверов.
  Наружу открыт только HTTPS мини-приложения, и каждый его запрос проверяется по подписи Telegram.
- Все данные — в папке `data/` (на сервере — `/var/lib/finbot/data`): база `finbot.db` (SQLite),
  фото целей в `photos/`, лог `bot.log`.
- Отвечает **только владельцу** и только в личке. Чужому бот один раз сообщит его Telegram ID
  (чтобы владелец, перепутавший ID, сразу понял, что поправить), и больше ничего.
- Токен хранится только в `.env` (на сервере — в `/etc/finbot.env`). В git он не попадает: `.env` и `data/` в `.gitignore`.
- Бэкап: **⚙️ Настройки → 💾 Бэкап базы** — пришлёт файл базы в чат; на сервере ещё `finbot backup`.

## ⚙️ Настройки в `.env`

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `OWNER_ID` | твой Telegram ID; пусто — владельцем станет первый, кто нажмёт /start |
| `TIMEZONE` | часовой пояс напоминаний, например `Europe/Moscow` (по умолчанию — как в системе) |
| `DATA_DIR` | где хранить базу и фото (по умолчанию `./data`) |
| `AI_API_KEY` | ключ нейросети для категорий (Groq `gsk_…` или OpenRouter `sk-or-…`) |
| `AI_BASE_URL`, `AI_MODEL` | для другого OpenAI-совместимого сервиса (например, своего Ollama) |
| `PROXY` | прокси для Telegram, например `socks5://127.0.0.1:1080` (нужен `pip install aiohttp-socks`) |
| `TELEGRAM_API_URL` | свой адрес-зеркало Bot API, если `api.telegram.org` заблокирован |
| `WEBAPP_URL` | HTTPS-адрес мини-приложения (можно несколько через запятую — запасные); на сервере ставится сам |
| `WEBAPP_PORT`, `WEBAPP_HOST` | где бот слушает запросы приложения (по умолчанию `127.0.0.1:8080`) |

Всё остальное (процент в цели, валюта, жёсткость, время напоминаний) — в самом боте: **⚙️ Настройки**.

## ❓ Частые вопросы

**Бот пишет «Нет связи с Telegram».** Из России `api.telegram.org` часто недоступен. На компьютере — включи VPN.
На сервере — нужна локация за границей (или `PROXY` / `TELEGRAM_API_URL` в `/etc/finbot.env`).

**Бот не отвечает.** На сервере: `finbot doctor` — он проверит всё сам. Частые причины:
токен перевыпустили в @BotFather (`finbot token`), указан чужой Telegram ID (`finbot owner ТВОЙ_ID` —
свой ID бот пришлёт в ответ на любое сообщение), сервер в России (нужна заграничная локация),
бот запущен ещё и на ноутбуке (останови копию). Если бот отвечает «Бот ещё ни к кому не привязан» — нажми `/start`.

**Нет кнопки «Приложение».** На сервере: `finbot webapp` (или `finbot update`, если бот стоял раньше).
Если приложение не открывается — проверь в панели хостинга, что открыты входящие порты 80 и 443.

**Перевыпустил токен в @BotFather.** На сервере: `finbot token` и вставь новый. На компьютере — замени `BOT_TOKEN` в `.env`.
Цели, фото и записи никуда не денутся — бот тот же, меняется только ключ.

**Хочу сменить владельца.** На сервере: `finbot owner НОВЫЙ_ID`. На компьютере — впиши ID в `OWNER_ID` в `.env` и перезапусти.

**Как начать с нуля?** ⚙️ Настройки → 🧨 Удалить все данные (нужно написать слово `УДАЛИТЬ`).

**Уже есть накопления.** Создай цель → ➕ Пополнить → «🏦 Деньги, отложенные ещё до бота».
Текущие деньги на карте — ⚙️ Настройки → 💼 Задать остаток на расходы.

## 🛠 Для разработчиков

```
finbot/
  app.py          сборка диспетчера и запуск
  db.py           SQLite: записи + движения денег (балансы всегда считаются из движений)
  money.py        суммы в копейках, разбор «2к», распределение по долям без потери копеек
  parsing.py      быстрый ввод, даты, время
  categories.py   категории и словарь
  classify.py     выбор категории: память → словарь → (нейросеть)
  ai.py           необязательная нейросеть (OpenAI-совместимый API)
  motivation.py   фразы в стиле Гоггинса (2 уровня жёсткости)
  reports.py      баланс, утренний/вечерний отчёт, вердикты
  scheduler.py    напоминания
  handlers/       экраны и кнопки
  webapp/         мини-приложение: API с проверкой подписи Telegram + страница без внешних скриптов
deploy/           установка на сервер (systemd), HTTPS для мини-приложения (Caddy) и команда finbot
tests/            unit-тесты, сквозные сценарии с имитацией Telegram API, fuzz-тесты, тест приложения в браузере
```

Все деньги хранятся в копейках (целые числа), балансы не хранятся, а считаются из таблицы движений —
поэтому отмена любой записи точно восстанавливает все суммы. Работа с базой идёт в отдельном потоке
одной транзакцией на операцию, обновления Telegram обрабатываются строго по очереди.

```bash
pip install -r requirements-dev.txt
pytest                      # быстрый прогон
FUZZ_SEEDS=300 pytest tests/test_fuzz.py   # долгий случайный прогон
pip install playwright && playwright install chromium && pytest tests/test_webapp_ui.py   # приложение в браузере
```
